# Tikfeed Lite 🚀

Aplikasi pemutar video pendek vertikal (*Vertical Video Feed*) ala TikTok versi **Lite** yang dikembangkan khusus untuk berjalan lancar di smartphone, tanpa modal, dan di-hosting gratis 100% menggunakan **GitHub Pages**.

---

## 📁 Struktur Project (4 File Modular)

```text
tikfeed-lite/
│
├── index.html         # Struktur HTML5, Top & Bottom Navigation Bar, dan Modal Komentar
├── style.css          # Styling kustom, Glassmorphism, Responsive Viewport, Animasi Vinyl
├── app.js             # Data Feed Video, Logika Autoplay, Swiper Integration, & Interactive Controls
└── README.md          # Dokumentasi Panduan Project
